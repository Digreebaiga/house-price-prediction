# 🏠 House Price Prediction
End-to-end House Price Prediction Project using python and Machine Learning

## 📌 Project Overview

This project uses **Machine Learning** to predict house prices based on various property-related features.

The project follows an end-to-end Machine Learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation, and prediction.

## 🎯 Objective

To develop a Machine Learning model that can predict house prices accurately using historical housing data.

## 🔄 Project Workflow

```text
Data Collection
      ↓
Exploratory Data Analysis
      ↓
Data Preprocessing
      ↓
Select Model
      ↓
Model Training
      ↓
Model Evaluation
      ↓
Price Prediction
```
